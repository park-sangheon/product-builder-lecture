# Project Blueprint

## Overview

A modern and visually appealing web application that generates six unique lottery numbers between 1 and 45. The design is inspired by modern web trends, featuring a dynamic space-themed background, subtle animations, and a clean user interface.

## Features

*   **Number Generation:** Generates six unique random numbers between 1 and 45.
*   **Dynamic Display:** Displays the generated numbers with a "pop-in" animation and a staggered effect.
*   **Modern UI:** Features a beautiful space-themed background, a background watermark with the address "dhlottery.co.kr", and improved styling for the button and number display.
*   **Color-Coded Numbers:** The generated numbers are color-coded based on their value for easier identification.
